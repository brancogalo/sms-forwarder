✨ O QUE VAI ACONTECER:

Quando você fazer PUSH para o GitHub:

1. GitHub Actions detecta mudanças
2. Inicia compilação automática
3. Compila PC App (EXE para Windows)
4. Compila Android App (APK)
5. Cria Release com TUDO pronto

🚀 PASSO A PASSO:

### PASSO 1: Criar conta GitHub (5 minutos)

1. Ir em: https://github.com/signup
2. Criar conta (email + senha)
3. Pronto!

### PASSO 2: Upload do projeto (5 minutos)

#### Opção A: Usando Git (recomendado)

```bash
# Abrir CMD/PowerShell na pasta sms-forwarder

# 1. Inicializar Git
git init

# 2. Adicionar arquivos
git add .

# 3. Fazer commit
git commit -m "Initial commit - SMS Forwarder"

# 4. Conectar ao GitHub
git remote add origin https://github.com/SEU_USUARIO/sms-forwarder.git

# 5. Fazer push
git branch -M main
git push -u origin main
```

#### Opção B: Interface web (mais fácil)

1. Ir em: https://github.com/new
2. Criar novo repositório
3. Nome: sms-forwarder
4. Descrição: SMS Forwarder System
5. Criar repositório
6. Clicar em "Upload files"
7. Arrastar pasta sms-forwarder inteira
8. Commit

### PASSO 3: GitHub vai compilar automaticamente!

1. Você faz o push
2. GitHub Actions inicia
3. Compila PC App EXE
4. Compila Android APK
5. Cria Release com tudo pronto

### PASSO 4: Baixar arquivos prontos

1. Ir em: https://github.com/SEU_USUARIO/sms-forwarder
2. Lado direito: "Releases"
3. Release "sms-forwarder-v1.0"
4. Baixar:
   - SMS Forwarder.exe (PC)
   - app-debug.apk (Android)
